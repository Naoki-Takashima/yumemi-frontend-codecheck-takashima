# API 項目定義書

ブラウザは上流 API を直接叩かない。**同一オリジンの BFF（Route Handler）だけ**を叩く。

```
ブラウザ  →  /api/*（BFF）  →  frontend-engineer-codecheck-api.mirai.yumemi.io
```

API キーは BFF 側の `src/features/population/server/yumemiApi.ts` だけが読む。

---

## 1. BFF のエンドポイント（API）

### API-01 `GET /api/prefectures`

都道府県一覧を返す。`src/app/api/prefectures/route.ts`

| 項目                  | 内容                                                               |
| --------------------- | ------------------------------------------------------------------ |
| リクエストパラメータ  | なし                                                               |
| 成功時                | `200` / `{ "result": Prefecture[] }`                               |
| キャッシュ            | `public, max-age=0, s-maxage=86400, stale-while-revalidate=604800` |
| 上流への `revalidate` | 86400 秒（24 時間）                                                |

レスポンス例

```json
{
  "result": [
    { "prefCode": 1, "prefName": "北海道" },
    { "prefCode": 2, "prefName": "青森県" }
  ]
}
```

### API-02 `GET /api/population`

指定した都道府県の人口構成を返す。`src/app/api/population/route.ts`

| 項目                  | 内容                                                             |
| --------------------- | ---------------------------------------------------------------- |
| リクエストパラメータ  | `prefCode`（**必須**）                                           |
| 成功時                | `200` / `{ "result": PopulationComposition }`                    |
| キャッシュ            | `public, max-age=0, s-maxage=3600, stale-while-revalidate=86400` |
| 上流への `revalidate` | 3600 秒（1 時間）                                                |

#### リクエストパラメータ

| ID     | 名前       | 型   | 必須 | 値の範囲 | 不正時                      |
| ------ | ---------- | ---- | ---- | -------- | --------------------------- |
| DAT-01 | `prefCode` | 整数 | ○    | 1 〜 47  | `400` / `INVALID_PREF_CODE` |

検証は `src/features/population/prefCode.ts` の `parsePrefCode`。**数字のみで構成された文字列**であることを正規表現で確かめてから数値に変換する。`1.5` `-1` `1a` `0` `48` はいずれも不正。

レスポンス例

```json
{
  "result": {
    "boundaryYear": 2020,
    "data": [
      {
        "label": "総人口",
        "data": [
          { "year": 1960, "value": 5039206 },
          { "year": 1965, "value": 5171800 }
        ]
      }
    ]
  }
}
```

## 2. データ項目（DAT）

型は `src/features/population/types.ts` に zod スキーマとして定義し、TypeScript の型は `z.infer` で導出する。上流のレスポンスはすべてこのスキーマで検証してから使う。

### Prefecture — 都道府県

| ID     | 項目名     | 論理名         | 型     | 必須 | 説明                                               |
| ------ | ---------- | -------------- | ------ | ---- | -------------------------------------------------- |
| DAT-02 | `prefCode` | 都道府県コード | 整数   | ○    | 1 〜 47。線の色と点の形の決定にも使う              |
| DAT-03 | `prefName` | 都道府県名     | 文字列 | ○    | 例: `東京都`。チェックボックスのラベルと凡例に表示 |

### PopulationComposition — 人口構成（1 都道府県分）

| ID     | 項目名         | 論理名             | 型                   | 必須 | 説明                                              |
| ------ | -------------- | ------------------ | -------------------- | ---- | ------------------------------------------------- |
| DAT-06 | `boundaryYear` | 実績と推計の境界年 | 整数                 | ○    | この年より**後**が推計値。多くの都道府県で `2020` |
| DAT-04 | `data`         | 系列の配列         | `PopulationSeries[]` | ○    | 総人口・年少人口・生産年齢人口・老年人口の 4 系列 |

### PopulationSeries — 系列

| ID     | 項目名  | 論理名   | 型                  | 必須 | 説明                                                                                                           |
| ------ | ------- | -------- | ------------------- | ---- | -------------------------------------------------------------------------------------------------------------- |
| DAT-05 | `label` | 系列名   | 文字列              | ○    | `総人口` / `年少人口` / `生産年齢人口` / `老年人口`。**日本語**。`POPULATION_TYPE_LABELS` で内部値と対応づける |
| —      | `data`  | 点の配列 | `PopulationPoint[]` | ○    | 年ごとの値                                                                                                     |

### PopulationPoint — 1 点

| ID     | 項目名  | 論理名   | 型   | 必須     | 説明                                                     |
| ------ | ------- | -------- | ---- | -------- | -------------------------------------------------------- |
| DAT-07 | `year`  | 年度     | 整数 | ○        | グラフの X 軸。1960 〜 2045 年の 5 年刻み、計 18 点      |
| DAT-08 | `value` | 人口数   | 数値 | ○        | グラフの Y 軸。単位は人                                  |
| DAT-09 | `rate`  | 構成割合 | 数値 | **任意** | 総人口以外の系列にのみ存在する。**この画面では使わない** |

## 3. エラーレスポンス

すべてのエラーは同じ形で返す。

```json
{
  "error": {
    "code": "UPSTREAM_ERROR",
    "message": "データを取得できませんでした。時間をおいて再度お試しください。"
  }
}
```

| ID     | 項目名          | 型     | 必須 | 説明                             |
| ------ | --------------- | ------ | ---- | -------------------------------- |
| DAT-10 | `error.code`    | 文字列 | ○    | 下表のいずれか                   |
| DAT-11 | `error.message` | 文字列 | ○    | 利用者に見せる文言。**常に定型** |

### コード一覧

| `code`                 | HTTP | 発生条件                                                | `message`                                                      |
| ---------------------- | ---- | ------------------------------------------------------- | -------------------------------------------------------------- |
| `INVALID_PREF_CODE`    | 400  | `prefCode` が 1 〜 47 の整数でない                      | prefCode には 1 以上 47 以下の整数を指定してください。         |
| `UPSTREAM_ERROR`       | 502  | 上流が 2xx 以外を返した／レスポンスがスキーマと合わない | データを取得できませんでした。時間をおいて再度お試しください。 |
| `UPSTREAM_UNAVAILABLE` | 503  | 上流に到達できない／API キーが未設定                    | データを取得できませんでした。時間をおいて再度お試しください。 |
| `INTERNAL_ERROR`       | 500  | 上記以外                                                | データを取得できませんでした。                                 |

**内部事情は返さない。** 上流の URL・ステータスコード・スキーマの差分は `message` に含めず、`console.error` にだけ出す。

クライアント側で JSON として読めなかった場合は、`fetchJson` が `code: "UNKNOWN"` / `message: "データを取得できませんでした。"` を補う。

## 4. 上流 API（参考）

BFF からのみ呼ぶ。ベース URL は `https://frontend-engineer-codecheck-api.mirai.yumemi.io`。

| パス                                                          | 用途         | 呼び出し元 |
| ------------------------------------------------------------- | ------------ | ---------- |
| `GET /api/v1/prefectures`                                     | 都道府県一覧 | API-01     |
| `GET /api/v1/population/composition/perYear?prefCode=<1..47>` | 人口構成     | API-02     |

- 認証は `X-API-KEY` ヘッダー。値は環境変数 `YUMEMI_API_KEY`
- レスポンスは `{ message, result }` のエンベロープ。**エンベロープ → `result` の順に二段で検証**する

## 5. 画面向けの変換

グラフに渡す前に `src/features/population/lib/toChartSeries.ts` で形を変える。

| 変換                  | 内容                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| 系列の抽出            | 選択中の種別（URL-02）に対応する `label` の系列だけを取り出す                                  |
| 行への転置            | 都道府県ごとの配列を、**年を軸にした 1 つの表**にまとめる。列名は `prefName`                   |
| 年の統合              | 全都道府県の `year` を集めて昇順に並べる。値の無い年は `undefined`（線をつながない）           |
| `boundaryYear` の集約 | 複数選択時は**最小値**を採る。「ここから先は推計が混ざりうる」境界なので早い年を採るのが安全側 |
| 該当系列が無い場合    | その都道府県を除外する（エラーにはしない）                                                     |

変換後の形

```ts
{
  rows: [{ year: 1960, 東京都: 9683802, 大阪府: 5504746 }, ...],
  prefNames: ['東京都', '大阪府'],
  boundaryYear: 2020,
}
```
