## 2. 都道府県セレクター（SEL）

`src/features/population/components/PrefectureSelector/index.tsx`
`fieldset` + `legend` のグループ。`legend` は「都道府県」。

### 通常状態

| ID     | 項目名                   | 種別                 | 初期値            | 制限・検証                                               | 振る舞い                                                                                                         | 取得元          |
| ------ | ------------------------ | -------------------- | ----------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------- |
| SEL-01 | 都道府県チェックボックス | checkbox × 47        | すべて未選択      | 同時選択は最大 **10 件**（`MAX_SELECTABLE_PREFECTURES`） | ON で当該県の人口構成を取得し、グラフに線を追加。OFF で線を削除。いずれも `URL-01` を書き換える                  | DAT-02          |
| SEL-02 | 都道府県名               | ラベル文字列         | —                 | —                                                        | クリックでも SEL-01 を切り替えられる（`label` が `input` を包む）                                                | DAT-03          |
| SEL-03 | 選択件数                 | テキスト             | `0 / 10 件選択中` | —                                                        | 選択のたびに更新。`aria-live="polite"` で読み上げる                                                              | SEL-01 の選択数 |
| SEL-04 | 上限到達時の案内         | テキスト             | 非表示            | —                                                        | 選択数が上限に達したときだけ「（他の都道府県を選ぶには、いずれかの選択を外してください）」を SEL-03 の後ろに追加 | SEL-01 の選択数 |
| SEL-05 | すべて解除               | ボタン（リンク表示） | 非活性            | —                                                        | 押すと選択をすべて解除。選択 0 件のときは非活性                                                                  | SEL-01 の選択数 |

#### SEL-01 の活性・非活性

| 条件                                | 状態                                                 |
| ----------------------------------- | ---------------------------------------------------- |
| 選択数 < 10                         | すべて活性                                           |
| 選択数 = 10 かつ 当該項目が選択済み | **活性**（外せないと上限から抜け出せなくなるため）   |
| 選択数 = 10 かつ 当該項目が未選択   | 非活性。`data-disabled` を付与し、視覚的にも薄くする |

#### 表示順・レイアウト

- 表示順は API のレスポンス順（`prefCode` の昇順）
- 列数はメディアクエリではなく grid の `auto-fill` で決まる。画面幅に応じて増減し、**最小 3 列**を下回らない

## 3. 人口種別タブ（TAB）

`src/features/population/components/PopulationTypeTabs/index.tsx`
`role="tablist"` の自前実装。`aria-label="人口種別"`。

| ID     | 項目名       | 種別 | 内部値    | 初期値     | 振る舞い                                                    |
| ------ | ------------ | ---- | --------- | ---------- | ----------------------------------------------------------- |
| TAB-01 | 総人口       | タブ | `total`   | **選択中** | 押すとグラフの系列を総人口に切り替え、`URL-02` を書き換える |
| TAB-02 | 年少人口     | タブ | `young`   | —          | 同上                                                        |
| TAB-03 | 生産年齢人口 | タブ | `working` | —          | 同上                                                        |
| TAB-04 | 老年人口     | タブ | `elderly` | —          | 同上                                                        |

- 表示ラベルは `POPULATION_TYPE_LABELS` が内部値から引く。**URL には日本語を載せない**ため内部値と表示を分けている
- 選択中のタブだけが `aria-selected="true"` かつ `tabIndex=0`。他は `tabIndex=-1`

#### キーボード操作

| キー   | 動作                               |
| ------ | ---------------------------------- |
| `→`    | 次のタブへ。末尾では先頭へ回り込む |
| `←`    | 前のタブへ。先頭では末尾へ回り込む |
| `Home` | 先頭のタブへ                       |
| `End`  | 末尾のタブへ                       |

移動と同時に選択も切り替わる（自動選択方式）。

## 4. グラフ（CHT）

`src/features/population/components/PopulationChart/index.tsx`
Recharts の折れ線グラフ。`role="tabpanel"` の中に置く。

| ID     | 項目名     | 種別           | 表示内容                                          | 書式                                                                          | 取得元 |
| ------ | ---------- | -------------- | ------------------------------------------------- | ----------------------------------------------------------------------------- | ------ |
| CHT-01 | X 軸目盛り | 数値           | 年度                                              | そのまま（例: `1965`）。1960 〜 2045 年の 5 年刻み                            | DAT-07 |
| CHT-02 | X 軸ラベル | テキスト       | 年度                                              | 固定値                                                                        | —      |
| CHT-03 | Y 軸目盛り | 数値           | 人口数                                            | 短縮表記。1 万以上は「万」、1 億以上は「億」（例: `1200万`）。小数第 1 位まで | DAT-08 |
| CHT-04 | Y 軸ラベル | テキスト       | 人口数                                            | 固定値                                                                        | —      |
| CHT-05 | 折れ線     | 線 × 選択件数  | 都道府県ごとの推移                                | —                                                                             | DAT-08 |
| CHT-06 | 凡例       | 記号＋テキスト | 都道府県名                                        | —                                                                             | DAT-03 |
| CHT-07 | 注記       | テキスト       | ※ &lt;boundaryYear&gt; 年より後の値は推計値です。 | —                                                                             | DAT-06 |

### CHT-05 折れ線の見た目

| 属性           | 決め方                                                                                                |
| -------------- | ----------------------------------------------------------------------------------------------------- |
| 色             | **`prefCode` から算出**（`lib/seriesColor.ts`）。選択順ではないため、外して付け直しても色が変わらない |
| 点の形         | `prefCode` から算出。`circle` / `square` / `triangle` / `diamond` の 4 種                             |
| 線幅           | 2px                                                                                                   |
| 欠測値         | 線をつながない（`connectNulls={false}`）                                                              |
| アニメーション | なし                                                                                                  |

- 色は白背景に対して **3:1 以上**を保証（WCAG 1.4.11）
- 点の形を色相の周回ごとに変えることで、色覚に依存しない手がかりを持たせる
- 凡例の並び順は `prefCode` の昇順

### CHT-08 ツールチップ

ホバー / フォーカスした年に表示する。

| 項目         | 内容                                          | 書式                                 |
| ------------ | --------------------------------------------- | ------------------------------------ |
| 年           | 対象の年度                                    | `1965 年`                            |
| 色見本       | 系列の色                                      | 正方形                               |
| 都道府県名   | 系列名                                        | —                                    |
| 人口数       | その年の値                                    | 桁区切り＋単位（例: `1,234,567 人`） |
| 推計値の注記 | `boundaryYear` より後の年のときだけ「推計値」 | —                                    |

行の並びは**その年の人口数の降順**（`lib/sortTooltipItems.ts`）。

### アクセシビリティ

| ID     | 項目名               | 内容                                                                                                                                                                            |
| ------ | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CHT-09 | グラフの代替テキスト | 視覚的に隠したテキストで内容を読み上げる。「&lt;種別&gt;の推移。対象は&lt;都道府県名&gt;。&lt;開始年&gt; 年から&lt;終了年&gt; 年まで。&lt;boundaryYear&gt; 年より後は推計値。」 |

グラフ本体は `aria-hidden="true"`。SVG の内部要素を読み上げても意味が通らないため、CHT-09 で代替する。

## 5. 状態表示（MSG）

`src/features/population/components/PopulationDashboard/index.tsx`

| ID     | 項目名               | 表示条件                    | 表示内容                                                                             |
| ------ | -------------------- | --------------------------- | ------------------------------------------------------------------------------------ |
| MSG-01 | 未選択メッセージ     | 選択 0 件                   | 都道府県を選択すると、人口の推移を表示します。                                       |
| MSG-02 | 読み込み中メッセージ | 選択あり かつ 取得済み 0 件 | スピナー＋「人口データを読み込んでいます」                                           |
| MSG-03 | 部分失敗の通知       | 一部の都道府県の取得に失敗  | 「&lt;都道府県名&gt;のデータを取得できませんでした。」＋再試行ボタン。`role="alert"` |
| MSG-04 | 読み上げ用の状況通知 | 常時                        | `role="status"` で以下のいずれか。視覚的には非表示                                   |

#### MSG-04 の文言

| 条件                    | 文言                                                |
| ----------------------- | --------------------------------------------------- |
| 選択 0 件               | 都道府県は選択されていません。                      |
| 選択あり・取得済み 0 件 | 人口データを読み込んでいます。                      |
| 取得済みあり            | &lt;件数&gt; 件の都道府県をグラフに表示しています。 |

### 追加取得中の扱い

すでに描けているグラフはそのまま残す。読み込み中の重ね表示は**行わない**。取得が速いと目印が一瞬で消え、ちらつくだけで読めなかったため。

## 共通の表示ルール

| 項目                          | ルール                                              |
| ----------------------------- | --------------------------------------------------- |
| 操作部品の最小サイズ          | 44 × 44px（`--tap-target-min`）                     |
| 本文のコントラスト比          | 背景に対して 4.5:1 以上（WCAG 1.4.3）               |
| UI 部品の輪郭のコントラスト比 | 背景に対して 3:1 以上（WCAG 1.4.11）                |
| フォーカス表示                | キーボード操作時のみ 3px の輪郭（`:focus-visible`） |
| アニメーション                | `prefers-reduced-motion: reduce` で停止             |
